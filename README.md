# Vozentra

Intérprete de voz local para Windows x64. Habla en español y recibe voz en inglés, o invierte el perfil. Incluye jerga personalizable y funciona mediante dispositivos de audio virtuales.

**Beta gratuita 0.8.14.** La precisión, la latencia y la compatibilidad dependen del equipo y de la llamada. Primera instalación en otro PC y pruebas prolongadas siguen en validación.

Este repositorio distribuye instaladores, manuales, hashes y notas de versión. El código de la aplicación se desarrolla en un repositorio privado. Vozentra es software propietario de Matias Alexander Polhwein Lara; los componentes de terceros conservan sus licencias y avisos incluidos con la aplicación.

El instalador incluye los modelos locales. Los controladores de audio virtual y otros requisitos se obtienen desde sus proveedores, con sus propias condiciones. El MSI no tiene firma Authenticode de Windows; puede aparecer una advertencia de editor desconocido. No instales un archivo si no coincide con el hash publicado.

Desde 0.8.14, Ajustes → Actualizaciones permite buscar futuras versiones, descargar y verificar e instalar al cerrar. El catálogo inicial incluye esta versión como base de recuperación. Las versiones anteriores requieren instalar 0.8.14 manualmente. Cerrar la aplicación descarta audio y transcripción de la sesión. Cambios materiales de términos requieren el instalador manual.

## English

Vozentra is a local Windows x64 voice interpreter with English/Spanish profiles and custom glossaries. **Free beta 0.8.14.** Download the MSI above, follow the bilingual manual, and configure the required audio devices. Accuracy and latency vary. Installation on another PC and extended testing remain under validation.

The application source is maintained privately. This repository contains distribution materials; the product is proprietary and third-party components retain their own licenses. The installer includes local models; drivers and other prerequisites come from their vendors. The MSI is not Windows Authenticode signed. Check the published SHA-256 before installing.

Version 0.8.14 introduces Settings → Updates for future releases, verified downloads and install on exit. Earlier versions need a manual installation of 0.8.14. Closing discards pending session audio and transcript. Material changes to terms require the manual installer. See the website for support, terms and privacy in English.
