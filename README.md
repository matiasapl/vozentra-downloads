# Vozentra

Intérprete de voz local para Windows x64. Habla en español y recibe voz en inglés, o invierte el perfil. Incluye jerga personalizable y funciona mediante dispositivos de audio virtuales.

**Beta gratuita 0.8.16.** La precisión, la latencia y la compatibilidad dependen del equipo y de la llamada. Primera instalación en otro PC y pruebas prolongadas siguen en validación.

## English

Vozentra is a local Windows x64 voice interpreter with English/Spanish profiles and custom glossaries. **Free beta 0.8.16.** Download the MSI above, follow the bilingual manual, and configure the required audio devices. Accuracy and latency vary. Installation on another PC and extended testing remain under validation.

The application source is maintained privately. This repository contains distribution materials; the product is proprietary and third-party components retain their own licenses. The installer includes local models; drivers and other prerequisites come from their vendors. The MSI is not Windows Authenticode signed. Check the published SHA-256 before installing.

To update from 0.8.14, download the new MSI, close Vozentra and run it without renaming it. This release is offered as a manual download while migration from the older updater is validated. Closing discards pending session audio and transcript. Material changes to terms require acceptance through the installer.
